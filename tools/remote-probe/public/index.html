tanacode の確かめ

遠隔操作の「先に確かめること」（Issue #464）を試すページ。Safari と、ホーム画面に置いたもの（PWA）の両方で開いて、上から順に押してください。

1. 開き方

開いたときの URL・フラグメント・PWA として開いているか。Safari で開いたときに置いた印が、PWA から見えるか。


  


  

    
2. 接続元とヘッダー

    
Mac のサーバーから見た接続元（tailscale serve の後ろで 127.0.0.1 に見えるか）と、転送が付けたヘッダー。

    
    

  


  

    
3. Cookie

    
Safari で「置く」を押し、ホーム画面に置いた PWA で「確かめる」を押す。Safari の Cookie が PWA に写るか。

    
    
    

  


  

    
4. 束縛の鍵（取り出せない P-256）

    
PWA で「作る」を押す。アプリを閉じる・iPhone を再起動する・数日たつ、などのあとに「確かめる」を押して、鍵が残っていて署名が通るか。

    
    
    

  


  

    
5. パスキー

    
RP ID はこのページのホスト名。PWA で登録とログインを何度か試し、安定して使えるか。BE・BS・signCount も見る。

    
    
    

  


  

    
6. カメラ

    
PWA の中でカメラが開けるか（QR を読む道に使う）。

    
    
    

  


  

    
7. Web Push

    
PWA で「購読する」を押して許可し、「送ってもらう」で通知が届くか。PWA を閉じた状態でも届くか。

    
    
    

  


  

    
8. WebSocket

    
tailscale serve を通って WebSocket がつながるか。往復の時間。

    
    

  


  

    
9. 結果を送る

    
ここまでの結果を Mac のサーバー（data/results.jsonl）に送る。下の文をそのまま写して渡してもよい。
